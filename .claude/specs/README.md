# Specs

What was decided and why, in the order it happened. `the-mission.md` is the brief this repository
was built from. Numbered files are plans and records: a plan is written before the work, then kept
as the record of what shipped (with a "Status" line updated), never deleted. A backlog of open items
lives in `04-backlog.md` and is the only file here that is edited rather than appended.

| file | what |
| --- | --- |
| `the-mission.md` | the operator's brief (2026-10-08) |
| `01-repo-structure.md` | the layout, the tools chosen, the reasons, what was verified |
| `02-month-1-test-plan.md` | the first campaigns: structure, events, budgets, decision rules |
| `03-creative-portfolio-plan.md` | how the few-hundred-creative portfolio is produced, in what order, at what cost |
| `04-backlog.md` | open items, owner-side actions, questions |
- `05-first-100.md` — the first 100 diverse, localised creatives: master list, quality bar, review loop, waves (2026-10-09)
- `06-launch-schedule.md` — when and how 001 (uaru, 100 PLN/day) and 002 (pl, 75 PLN/day) go live, the blockers from `/verify`, decision dates (2026-10-09)
