# Brand kit

Copied from `../svora-landing/contents/resources` (the design kit) on 2026-10-08, plus Roboto Condensed
from Google Fonts (OFL). Facts and colour hexes live in `settings/brand.yaml`; voice rules in
`.claude/skills/svora-brand/SKILL.md`.

- `logos/` — wordmark (orange / light / black), submark, "S" marks, 3D variants. Overlay them; never regenerate.
- `fonts/roboto-condensed/` — variable 100–900, Latin + Latin-ext + Cyrillic → every PL/UA/RU/EN overlay.
- `fonts/antonio/` — Bold etc., Latin only → Latin display lines.
- `fonts/smile-power/` — decorative, ASCII only, licence per the kit receipt → avoid in ads.
- `color-palette.png` — the kit's palette sheet.
